# Security Policy

Thank you for helping keep ClearBreath and its community safe.

## Supported Versions

| Version | Supported |
| --- | --- |
| 0.0.x | Yes |
| < 0.0.0 | No |

## Reporting a Vulnerability

Please report suspected vulnerabilities privately by email:

- `rahulmistry.sde@gmail.com`

Do not open a public GitHub issue for a security vulnerability.

If the issue is specific to this repository, report it directly for this
repository. If you found a vulnerability in another PureBreathLabs repository,
please report it through that repository's security channel or contact the
maintainer directly.

## What to Include

Please include as much of the following as possible:

- A clear summary of the issue and its impact
- The affected version, commit, or deployment context
- Reproduction steps or a proof of concept
- Any logs, screenshots, or request samples that help explain the issue
- Suggested mitigations if you have them

## Response Timeline

We aim to:

- Acknowledge receipt within 48 hours
- Provide an initial assessment within 7 days
- Share follow-up status updates until the issue is resolved or mitigated

## Coordinated Disclosure

Please give us a reasonable opportunity to investigate and ship a fix before
public disclosure. We will work with you on coordinated disclosure timing and
release notes.

## Recognition

If you would like public credit, we are happy to thank reporters in release
notes after the issue is resolved.
