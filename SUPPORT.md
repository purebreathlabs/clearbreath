# Support

## Getting Help

For setup questions, usage help, or contributor guidance:

- Use GitHub Discussions when they are enabled for this repository
- Until Discussions are enabled, open a blank GitHub issue with enough context
  for someone to help
- Check [CONTRIBUTING.md](CONTRIBUTING.md) for local development and pull
  request guidance

## Security

Follow the reporting instructions in [SECURITY.md](SECURITY.md).
